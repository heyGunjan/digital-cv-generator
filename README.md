Digital CV Generator

A responsive web application that allows users to create,
preview and print professional CVs directly from the browser.

Features
- Personal details
- Profile summary
- Photo upload
- Education
- Experience
- Projects
- Certifications
- Skills
- Add/Remove dynamic sections
- Input validation
- Live CV generation
- Print / Save as PDF
- Responsive design

Tech Stack
- HTML
- CSS
- JavaScript

How to Use
1. Enter your details
2. Add education, experience, projects, etc.
3. Click Generate CV
4. Preview your CV
5. Print or save it as PDF

Future Improvements
- AI-powered professional summary
- Multiple CV templates
- LocalStorage
- Dark mode
